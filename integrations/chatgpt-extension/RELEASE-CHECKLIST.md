# Release gates

- [ ] GitHub Actions static validation green for current head SHA
- [ ] Desktop Chrome unpacked extension installation tested
- [ ] Side panel opens and closes via extension action
- [ ] Local preferences persist across browser restart
- [ ] Command picker copies text without executing it
- [ ] Accessibility and responsive layout reviewed
- [ ] OAuth implemented with secure token handling and least-privilege scopes
- [ ] Context ingestion requires opt-in and supports deletion
- [ ] File uploads validated against backend endpoints and file size/type limits
- [ ] All sensitive actions honor host/provider confirmations
- [ ] Android-compatible experience tested separately
- [ ] Chrome Web Store listing, privacy disclosure, and review complete
- [ ] Production deployment verified independently

Do not merge or publish solely because this checklist exists. A passing static test does not establish functional integration.
