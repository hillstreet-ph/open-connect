# Skill sources for Open-Connect

These folders contain the four user-provided skill packages published in the Open-Connect Marketplace. Each directory preserves its SKILL.md, supporting references, templates, tests, and scripts.

| Skill | Directory |
|---|---|
| Open Influencer Organizer | open-influencer-organize |
| Business English Conversation Helper | business-english-conversation-helper |
| Year Month Drive Organizer | organizing-numbered-year-month-files |
| Full-Stack Platform Operations | fullstack-platform-operations |

The Full-Stack package includes two shell scripts. Review their contents and target paths before running them. No credentials or business records are included.
